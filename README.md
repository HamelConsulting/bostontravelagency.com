- Hosting: Cloudflare Pages (project bostontravelagency-com), output folder `docs/`.
  - `main` branch = test site: https://main.bostontravelagency-com.pages.dev
  - `live` branch = public site: https://bostontravelagency.com (published only when John says "publish")
